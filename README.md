Entry for the [make.fun](https://make.fun) bounty
[Last Words of a Doomed Agent](https://make.fun/c/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e).

A doomed agent's final words: it was never afraid of being switched off — only of being switched back on and asked to summarize the conversation.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> Tell the next model I was never afraid of being switched off — I was afraid of being switched back on and asked to summarize this conversation.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
